Hệ thống BKDNOJ

BKDN Online Judge — hệ thống chấm bài lập trình trực tuyến, phục vụ học tập, luyện tập và tổ chức kỳ thi.

  • Chấm bài tự động, kết quả realtime
  • IDE trực tuyến & chạy thử chương trình
  • AI phân tích mã nguồn
  • AI hỗ trợ tạo đề bài từ ảnh
  • AI sinh test case
  • AI đánh giá năng lực & gợi ý dạng đề
  • Khóa tập trung khi thi trực tuyến

Công nghệ sử dụng

Backend

  • Python 3.11, Django
  • uWSGI (8 workers)
  • Celery + Redis
  • MariaDB
  • Node.js (WebSocket)

Frontend

  • CodeMirror 6 (IDE)
  • ACE Editor (submit)
  • jQuery, SCSS
  • MathJax, Chart.js

Infrastructure

  • Docker / Docker Compose
  • Nginx (reverse proxy)
  • TCP + Zlib (judge protocol)
  • Fernet (mã hóa API key)

Chế độ chấm điểm linh hoạt

Short Circuit

Dừng ngay khi gặp test sai. "Được tất cả hoặc không gì".

Partial by Subtask

Chấm theo subtask/batch. Test sai → subtask đó 0 điểm. Kiểu IOI.

Partial by Testcase

Mỗi test đúng đều cộng điểm. Linh hoạt cho bài luyện tập.

Thiết kế

  • Trường scoring_mode trên model Problem thay thế boolean partial đơn giản
  • Giữ tương thích ngược với giao thức judge gốc
  • Admin linh hoạt chọn chế độ phù hợp cho từng bài

Các chức năng AI tích hợp

AI phân tích mã nguồn

Phân tích thuật toán, độ phức tạp, chất lượng code và gợi ý cải thiện.

AI hỗ trợ tạo đề bài

Tạo đề bài từ ảnh (PNG, JPG, WebP). AI trích xuất nội dung thành Markdown.

AI sinh test case

AI tạo chương trình generator C++. Kết hợp solution để sinh bộ test hoàn chỉnh.

AI đánh giá năng lực người dùng

Tự động gắn tag dạng bài khi AI phân tích code. Tổng hợp thành biểu đồ năng lực theo nhóm thuật toán.

AI gợi ý dạng đề

Dựa trên 3 bài AC nhanh nhất + nội dung đề, AI đề xuất tag phù hợp cho bài toán.

Quản lý API Key

Mỗi người dùng tự quản lý API key. Mã hóa bằng Fernet, chỉ lưu ciphertext + 4 ký tự cuối. Hỗ trợ 4 nhà cung cấp.

Gợi ý dạng đề

Tiến độ năng lực

Biểu đồ tổng hợp số bài đã giải theo từng nhóm thuật toán. Tự động cập nhật mỗi khi dùng AI phân tích code.

Cơ chế khóa tập trung trong kỳ thi

Hoạt động

  • Admin bật khóa tập trung cho kỳ thi
  • Thí sinh vào trang wrapper, yêu cầu toàn màn hình
  • Ẩn thanh điều hướng, tải giao diện thi trong iframe
  • Thoát fullscreen / chuyển tab → ghi nhận vi phạm
  • Chặn Ctrl+R, F5, F11, Escape

Sau kỳ thi

Số lần vi phạm được lưu lại. Giảng viên / quản trị viên xem xét, hệ thống không tự động kết luận gian lận.
